# CLN2 Infusion Safety Monitor

An interpretable healthcare AI research prototype for identifying unusual infusion sessions in children receiving intraventricular cerliponase alfa for CLN2 disease.

## Project Overview

Children with CLN2 disease require repeated intraventricular infusions of cerliponase alfa. This project explores whether transparent safety rules and anomaly-detection methods can identify infusion records that may require additional clinical review.

The initial version will use synthetic data and consider factors such as:

- Number of access attempts
- Successful cerebrospinal fluid return
- Infusion duration
- Resistance during flushing
- Leakage or swelling
- Possible signs of infection
- Time since device implantation
- Previous device-related problems

## Planned Components

- Synthetic infusion-record generator
- Transparent safety-rule system
- Interpretable anomaly-detection model
- Model evaluation and visualizations
- Simple demonstration dashboard
- Automated tests and documentation

## Project Status

This project is currently in the initial planning stage. Its data definitions, implementation, evaluation approach, and documentation will be developed incrementally.

## Disclaimer

> **Research use only:** This project is not a medical device and has not been clinically validated. It must not be used to diagnose patients, recommend treatment, or make clinical decisions. Any synthetic data included in this repository will not represent real patients.
